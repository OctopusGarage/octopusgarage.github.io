# fluent-frame

> Local-first Chrome extension for bilingual YouTube subtitles and English learning notes.

## Metadata

- Category: Knowledge and Learning
- Language: TypeScript
- GitHub: https://github.com/OctopusGarage/fluent-frame
- Homepage: `Not published`

## Summary

fluent-frame turns YouTube videos into an English-learning workspace. It downloads real English captions, asks a local Codex or Claude CLI to produce corrected bilingual learning subtitles and phrase explanations, then renders them inside the video experience.

## Fits Into OctopusGarage

fluent-frame extends the OctopusGarage local-first learning loop. It keeps caption download, local agent execution, cache, notes, and diagnostics on the user's machine instead of routing learning workflows through a hosted LLM API.

## Best For

- Learning English while watching YouTube.
- Generating bilingual subtitles and phrase explanations with local agents.
- Keeping learning history and personal notes under local control.
