# tmux-claude-bot

> Control Claude Code and OpenAI Codex agents from Telegram, Feishu/Lark, a CLI, or a TUI.

## Summary

tmux-claude-bot keeps terminal-based coding agents reachable after they start running. It connects tmux sessions to Telegram, Feishu/Lark, a local CLI, and a terminal UI so an operator can send prompts, inspect output, manage multiple projects, and keep long-running work visible.

## Fits Into OctopusGarage

This is the flagship agent-control project in the OctopusGarage system. It anchors the pattern of leaving real work inside local terminal sessions while adding practical remote control and operator visibility around it.

## Best For

- Remote control of Claude Code and OpenAI Codex sessions.
- Multi-project agent workflows that need persistent tmux panes.
- Developers who want chat access without losing the raw terminal session.
